# Wrought Dataset v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Wrought character-dataset generator so every frame is a unique, race-correct character in the 002 look without the three AI tells, split into two lanes (suit character concepts / asset plates) that feed the reference-sheet → 3D contract, with every rule enforced by a test or a measurement.

**Architecture:** The prompt vocabulary (`scripts/dev/wrought_variants.py`) gains the axes the night run lacked — beastfolk subspecies, dragonborn skin ownership, nations, a structured face bundle, a living-skin clause — and sheds the words that produce the generic face. Two new vocabulary modules (`wrought_wardrobe.py`, `wrought_hair.py`) put the owner's Clothing Production Guide and the Bible's hair lists into code. The ComfyUI transport moves to `wrought_comfy.py` so the generator, the suit edit and the sheet test share one graph builder, including the native Krea 2 reference path. Three measurement modules (`wrought_tells.py`, `wrought_measures.py`, the existing `check_wrought.py`) gate batches against the owner's locks.

**Tech Stack:** Python 3.12 (`.venv`), ComfyUI v0.34.0 at `C:\sv_comfynext_v034` (read-only, HTTP only), Krea 2 family checkpoints (`loxsUtopicWorldKrea2_v10Quants` render, Qwen3-VL fp8 encoder, Qwen image VAE), Jarvis (`SpellBound-Engine/tools/jarvis`: vision `gemma4:12b` local, reason on spellnode), OpenCV / NumPy / Pillow, pytest with the repo's hermetic lane.

**Spec:** `docs/pipeline/wrought_dataset/DIRECTION_V2.md` (owner-approved 2026-09-05; §0 owner decisions, §3 anti-AI-look translation, §4 vocabulary v2, §5 lanes, §8 Jarvis's 14 joint rules, §9 suit/skin plates, canvas, composition).

## Global Constraints

- Prompts NEVER contain the token `WROUGHT` (it renders as text). The LoRA trigger `wrought style` lives only in caption `.txt` files.
- The 002-lead sentence (`WROUGHT_LEAD`) is always the FIRST sentence; the subject follows; `WROUGHT_TAIL` closes. Never subject-first, never clothes-first.
- Sampler lock: 52 steps, CFG 3.5, euler, simple, `ModelSamplingAuraFlow` shift 1.15. Do not retune to chase 002.
- Canvases: Lane A plates 1216×1728 (§9.4; the first six are a paint check against 002 before the size is committed); Lane B asset plates 768×1024; Lane B fit plates 768×1344; sheet views 1216×1728 (sides 832×1728).
- Assembled prompt ≤ 400 words, hard (DIRECTION_V2 §3.7 as amended 2026-09-06: the 002 lead alone is 76 words and is owner-locked, and the race-defining clauses are worth more than the encoder's ~300-word soft ceiling; measured per race in the Task 5 commit). A test enforces it. Dragonborn has a +60 allowance (four owned clauses no other race carries; ceiling measured ~445). The opt-in draconic alternate heads take a further +40 (authored records, not the race).
- Banned prompt words (§3.1): `gorgeous`, `flawless`, `smooth clear skin`, `elegant even features`, `perfect`, `masterpiece`, `8k`, `ultra detailed`, `hyperrealistic`, `airbrushed`, `beauty filter`. Photograph vocabulary is also banned in positives: `DSLR`, `film grain`, `Kodak`, `Fujifilm`, `f/1.8`, `bokeh`, `iPhone`, `snapshot`.
- `"asymmetric eyes"` is removed from every negative (§3.2).
- Beastfolk: six subspecies, human face, ONLY the animal ear pair, no human ear pair, human hair, no horns except small antlers on deer (owner decision 2).
- Dragonborn: SKIN owns the skin, LINEAGE owns scale colour / eyes / horn only; the garment clause forbids scale on clothing (§4).
- Never download a model or install a node pack without the owner's explicit approval (owner decision 6 approves ONLY the RAW-native 20-sheet test).
- The live ComfyUI tree is read-only; frames are fetched over HTTP (`/view`), never from a disk path. One runner per endpoint; distinct `--out` roots per endpoint (`runtime/wrought_v2` local, `runtime/wrought_v2_b` spellnode).
- Never run an Ollama model beside a render on the same box (Jarvis vision on the local 5090 only while the local ComfyUI is idle; the reasoner lives on spellnode and must not overlap a spellnode render).
- Records are JSON beside each frame; `runtime/` is gitignored — evidence goes to `docs/pipeline/wrought_dataset/evidence/` as JPG contact sheets.
- Every heuristic ships with the number that justified it (Doc 50 rule 1); every rule is enforced on the tree by a test, not at a site (Doc 50 rule 10).
- Commits: one task per commit, message body explains the why, trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` (the repo's current practice — see `git log -4`).
- Tests that talk to ComfyUI or Jarvis carry `@pytest.mark.needs_comfy` / `@pytest.mark.needs_network`; everything else must pass with the network blocked (conftest forbids undeclared sockets).
- Python for every command below: `.venv/Scripts/python.exe` from the repo root, with `PYTHONUTF8=1` set (cp1252 console encoding breaks on `≥` and similar).

```python
# scripts/dev/wrought_comfy.py
"""The ComfyUI transport and the two graphs every Wrought script submits.

Extracted from generate_wrought_dataset.py so the suit edit (Lane A), the asset plates (Lane B) and
the reference-sheet test submit through ONE builder. The reference graph is the core's own
Krea 2 style-reference template with the identity path kept and the style LoRA left out:
`TextEncodeQwenImageEditPlus(clip, vae, image1, prompt)` carries the reference latents into the
conditioning, `FluxKontextMultiReferenceLatentMethod(index_timestep_zero)` selects the core's
`ref_latents_method` for the Krea 2 forward. Grounded from
`comfyui_workflow_templates_json/templates/image_krea2_turbo_int8_image_style_reference.json`
on core v0.34.0, 2026-09-05 -- never from memory (Doc 50 rule 2).

Frames are fetched over HTTP (`/view`) and never read from a disk path: a disk path resolves on the
machine running THIS script, and pointing the harness at spellnode would copy the LOCAL output
directory's stale renders without an error (banked 1eb2c56).
"""
from __future__ import annotations

import json
import sys
import time
import urllib.parse
import urllib.request
from dataclasses import dataclass
from pathlib import Path

REPO = Path(__file__).resolve().parents[2]
sys.path.insert(0, str(REPO / "python"))
from comfy_prompt_client import _http_get_json, _upload_comfy_image  # noqa: E402

UNET = "loxsUtopicWorldKrea2_v10Quants.safetensors"
CLIP = "qwen3vl_4b_fp8_scaled.safetensors"
VAE = "qwen_image_vae.safetensors"
STEPS, CFG, SHIFT = 52, 3.5, 1.15


@dataclass
class Endpoint:
    api: str = "http://127.0.0.1:8188"

    def submit(self, graph: dict) -> str:
        body = json.dumps({"prompt": graph, "client_id": "sv-wrought-v2"}).encode()
        request = urllib.request.Request(f"{self.api}/prompt", data=body,
                                         headers={"Content-Type": "application/json"})
        return json.loads(urllib.request.urlopen(request, timeout=120).read())["prompt_id"]

    def wait(self, prompt_id: str, timeout_s: int = 900) -> list[str]:
        deadline = time.time() + timeout_s
        while time.time() < deadline:
            entry = (_http_get_json(self.api, f"/history/{prompt_id}", timeout=30) or {}).get(prompt_id)
            if entry:
                status = entry.get("status", {})
                if status.get("completed"):
                    return [i["filename"] for o in entry.get("outputs", {}).values()
                            for i in o.get("images", [])]
                if status.get("status_str") == "error":
                    return []
            time.sleep(2.0)
        return []

    def fetch(self, filename: str) -> bytes:
        url = f"{self.api}/view?filename={urllib.parse.quote(filename)}&type=output"
        with urllib.request.urlopen(url, timeout=180) as response:
            return response.read()

    def free_ram_gb(self) -> float:
        try:
            return _http_get_json(self.api, "/system_stats", timeout=15)["system"]["ram_free"] / 2**30
        except Exception:
            return -1.0

    def upload(self, path: Path) -> str:
        """Push a local plate into the endpoint's input folder; returns the name LoadImage takes."""
        return _upload_comfy_image(self.api, str(path))["name"]


def _base(positive: str, negative: str, seed: int, prefix: str, width: int, height: int,
          steps: int, cfg: float, unet: str | None, shift: float) -> dict:
    return {
        "1": {"class_type": "UNETLoader", "inputs": {"unet_name": unet or UNET, "weight_dtype": "default"}},
        "2": {"class_type": "CLIPLoader", "inputs": {"clip_name": CLIP, "type": "krea2"}},
        "3": {"class_type": "VAELoader", "inputs": {"vae_name": VAE}},
        "6": {"class_type": "CLIPTextEncode", "inputs": {"text": negative, "clip": ["2", 0]}},
        "5": {"class_type": "ModelSamplingAuraFlow", "inputs": {"model": ["1", 0], "shift": shift}},
        "7": {"class_type": "EmptySD3LatentImage",
              "inputs": {"width": width, "height": height, "batch_size": 1}},
        "8": {"class_type": "KSampler",
              "inputs": {"model": ["5", 0], "seed": seed, "steps": steps, "cfg": cfg,
                         "sampler_name": "euler", "scheduler": "simple", "positive": ["4", 0],
                         "negative": ["6", 0], "latent_image": ["7", 0], "denoise": 1.0}},
        "9": {"class_type": "VAEDecode", "inputs": {"samples": ["8", 0], "vae": ["3", 0]}},
        "10": {"class_type": "SaveImage", "inputs": {"images": ["9", 0], "filename_prefix": prefix}},
    }


def t2i_graph(positive: str, negative: str, seed: int, prefix: str, width: int, height: int,
              steps: int = STEPS, cfg: float = CFG, unet: str | None = None,
              shift: float = SHIFT) -> dict:
    g = _base(positive, negative, seed, prefix, width, height, steps, cfg, unet, shift)
    g["4"] = {"class_type": "CLIPTextEncode", "inputs": {"text": positive, "clip": ["2", 0]}}
    return g


def reference_edit_graph(positive: str, negative: str, seed: int, prefix: str, width: int,
                         height: int, reference_name: str, steps: int = STEPS, cfg: float = CFG,
                         unet: str | None = None, shift: float = SHIFT) -> dict:
    """Same character, new instruction: the reference plate rides the conditioning."""
    g = _base(positive, negative, seed, prefix, width, height, steps, cfg, unet, shift)
    g["11"] = {"class_type": "LoadImage", "inputs": {"image": reference_name}}
    g["4"] = {"class_type": "TextEncodeQwenImageEditPlus",
              "inputs": {"clip": ["2", 0], "vae": ["3", 0], "image1": ["11", 0], "prompt": positive}}
    g["12"] = {"class_type": "FluxKontextMultiReferenceLatentMethod",
               "inputs": {"conditioning": ["4", 0], "reference_latents_method": "index_timestep_zero"}}
    g["8"]["inputs"]["positive"] = ["12", 0]
    return g


def render(endpoint: Endpoint, graph: dict, target: Path) -> bool:
    files = endpoint.wait(endpoint.submit(graph))
    if not files:
        return False
    target.write_bytes(endpoint.fetch(files[0]))
    return True
```

```python
def identity_key(pick: dict) -> str:
    """One string per character. Two picks with the same key are the same person; a batch refuses that."""
    fields = ("race", "nation", "subspecies", "skin", "hair_colour", "hair_texture", "eyes",
              "face_bundle", "mark")
    return hashlib.sha1("|".join(str(pick.get(f, "")) for f in fields).encode()).hexdigest()[:16]


class IdentityRegistry:
    """Persisted set of identity keys across every batch under one out root."""

    def __init__(self, path: Path):
        self.path = path
        self.keys: dict[str, str] = json.loads(path.read_text(encoding="utf-8")) if path.exists() else {}

    def seen(self, key: str) -> bool:
        return key in self.keys

    def add(self, key: str, where: str) -> None:
        self.keys[key] = where
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.path.write_text(json.dumps(self.keys, indent=1), encoding="utf-8")
```

```python
class Outfit:
    race: str
    dialect: str
    rank: str
    profession: str
    occasion: str
    function: str
    condition: str
    dye: str
    materials: str
    slots: dict[str, str] = field(default_factory=dict)
    kit_wear: str = ""

    def key(self) -> str:
        return "|".join([self.dialect, self.rank, self.function] + [self.slots[s] for s in sorted(self.slots)])

    def _garments(self) -> str:
        order = ["under", "torso", "legs", "outer", "feet", "hands", "head", "belt", "accessory"]
        return ", ".join(self.slots[s] for s in order if self.slots.get(s))

    def worn_clause(self) -> str:
        """What she wears, said once, under 45 words: dialect cut, rank signal, the slots, one wear."""
        wear = f", {self.kit_wear}" if self.kit_wear else ""
        return (f"{self.dialect} cut ({DIALECTS[self.dialect]}), {self.rank} register, {self.dye}, "
                f"{ORNAMENT_BY_RANK[self.rank]}: {self._garments()}{wear}; {self.materials}")

    def plate_clause(self) -> str:
        """The same garments alone: Guide section 7.5, the clothes-only product plate."""
        return (f"{self.rank} {self.dialect} clothes on an empty mannequin, front view, the garments "
                f"alone with no figure: {self._garments()}; {self.dye}, {ORNAMENT_BY_RANK[self.rank]}, "
                f"{self.condition}; {self.materials}")

    def caption(self) -> str:
        return f"{self.rank} {self.dialect} outfit, {self._garments()}, {self.condition}"


def _weighted(rng: random.Random, options: list[tuple[str, int]]) -> str:
    return rng.choices([t for t, _ in options], weights=[w for _, w in options], k=1)[0]


def _slot(rng: random.Random, slot: str, dialect: str) -> str:
    table = SLOT_OPTIONS[slot]
    return rng.choice(table.get(dialect) or table["*"])


def draw_outfit(race: str, rng: random.Random, materials: str, dialect: str | None = None,
                rank: str | None = None) -> Outfit:
    dialect = dialect or rng.choice(RACE_DIALECTS.get(race, ["vernacular"]))
    rank = rank or _weighted(rng, RANKS)
    function = _weighted(rng, FUNCTION)
    slots = {s: _slot(rng, s, dialect) for s in SLOT_OPTIONS}
    if function != "civil":
        kit = DRAGONBORN_KIT if race == "dragonborn" else FIELD_KIT
        slots["outer"] = rng.choice(kit[function])
    if race == "dragonborn":
        slots = {k: v for k, v in slots.items()}
        for k, val in slots.items():
            assert "scale" not in val.lower(), (k, val)
    materials = ", ".join(m for m in materials.split(", ") if "scale" not in m.lower()) if race == "dragonborn" else materials
    return Outfit(race=race, dialect=dialect, rank=rank, profession=rng.choice(PROFESSION_BY_RANK[rank]),
                  occasion=rng.choice(OCCASION), function=function,
                  condition=rng.choice(CONDITION_BY_RANK[rank]), dye=DYE_BY_RANK[rank],
                  materials=f"materials: {materials}", slots=slots, kit_wear=rng.choice(KIT_WEAR))
```

```python
def _parse(text: str) -> dict | None:
    a, b = text.find("{"), text.rfind("}")
    if a == -1 or b == -1:
        return None
    try:
        return json.loads(text[a:b + 1])
    except json.JSONDecodeError:
        return None


def ask_json(path: Path, question: str, ask=None) -> dict:
    ask = ask or _jarvis_ask
    text = ask(question, str(thumb(Path(path))))
    parsed = _parse(text or "")
    return parsed if parsed is not None else {"error": (text or "")[:200]}


def read_frame(path: Path, ask=None) -> dict:
    r = ask_json(path, TELLS_QUESTION, ask)
    if "error" in r:
        return r
    r["ai_tells"] = [x for x in r.get("ai_tells", []) if x in TELLS]
    return r


def rates(readings: list[dict]) -> dict[str, float]:
    readable = [r for r in readings if "error" not in r]
    n = max(len(readable), 1)
    return {tell: sum(tell in r.get("ai_tells", []) for r in readable) / n for tell in TELLS}


def calibrate(paths: list[Path], out_json: Path, ask=None) -> dict:
    readings = [read_frame(p, ask) for p in paths]
    result = {"n": sum("error" not in r for r in readings), "rates": rates(readings),
              "frames": [str(p) for p in paths], "readings": readings}
    out_json.parent.mkdir(parents=True, exist_ok=True)
    out_json.write_text(json.dumps(result, indent=1), encoding="utf-8")
    return result


@dataclass
class GateVerdict:
    ok: bool
    n: int
    offending: list[dict] = field(default_factory=list)


def gate(batch: list[dict], keeper: dict, floor: float = FLOOR) -> GateVerdict:
    batch_rates = rates(batch)
    n = max(sum("error" not in r for r in batch), 1)
    offending = []
    for tell in TELLS:
        p = keeper["rates"].get(tell, 0.0)
        limit = max(floor, 2 * math.sqrt(p * (1 - p) / n))
        if batch_rates[tell] > p + limit:
            offending.append({"tell": tell, "batch_rate": batch_rates[tell], "keeper_rate": p, "limit": limit})
    return GateVerdict(ok=not offending, n=n, offending=offending)


AXES = ("tier", "dialect", "nation", "framing", "light", "subspecies", "appearance")


def covary(records: list[dict], tell: str) -> list[tuple[str, float]]:
    """Which axis VALUE carries the tell: rate of the tell among frames with that value, best first."""
    hits: dict[str, list[int]] = collections.defaultdict(list)
    for rec in records:
        v = rec.get("variation", {})
        carry = int(tell in rec.get("_tells", []))
        for axis in AXES:
            val = v.get(axis)
            if val:
                hits[f"{axis}={val}"].append(carry)
    scored = [(k, sum(xs) / len(xs)) for k, xs in hits.items() if len(xs) >= 2]
    return sorted(scored, key=lambda kv: -kv[1])


def _frames(args: list[str]) -> list[Path]:
    out: list[Path] = []
    for raw in args:
        p = Path(raw)
        out.extend(sorted(p.glob("*.png")) if p.is_dir() else [p])
    return out


def main() -> int:

        s.add_argument("--out", default=None)
```

```python
# scripts/dev/wrought_measures.py
"""Two plates of one character: does the suit keep the silhouette, and is it the same face?

DIRECTION_V2 section 9: the SKIN plate (two-piece, markings visible) is the material truth and the
SUIT plate (a reference edit of it) is the proportion truth. Both are Wrought-lit -- dark studio,
one key -- so `check_reference_sheet.subject_mask` (built for a light, flat ground) shatters on them
(documented there). This mask is the dark-ground counterpart: the ground is sampled from the border
and anything that differs from it in luma OR chroma by more than the tolerance is subject; the
largest component wins. The suit is mid-grey for this reason (a dark-grey suit on a near-black void
would not separate).

Thresholds: silhouette accept < 8 px at 1216 wide (Jarvis, section 9.6) -- restated after the first
twenty pairs, as Doc 50 rule 1 requires; face identity is RECORDED (MAE + normalised cross-
correlation on the largest Haar face) and not thresholded until twenty pairs exist.
"""
from __future__ import annotations

import json
import sys
from pathlib import Path

import cv2
import numpy as np
from PIL import Image
from scipy import ndimage

SILHOUETTE_LIMIT_PX_AT_1216 = 8.0
_CASCADE = None


def _rgb(path: Path) -> np.ndarray:
    return np.asarray(Image.open(path).convert("RGB"))


def dark_subject_mask(rgb: np.ndarray, tolerance: float = 28.0) -> np.ndarray:
    h, w, _ = rgb.shape
    border = np.concatenate([rgb[:8].reshape(-1, 3), rgb[-8:].reshape(-1, 3),
                             rgb[:, :8].reshape(-1, 3), rgb[:, -8:].reshape(-1, 3)]).astype(np.float32)
    ground = np.median(border, axis=0)
    diff = np.abs(rgb.astype(np.float32) - ground).max(axis=2)
    candidates = diff > tolerance
    candidates = ndimage.binary_opening(candidates, iterations=2)
    labels, count = ndimage.label(candidates)
    if count == 0:
        return candidates
    sizes = ndimage.sum(candidates, labels, index=np.arange(1, count + 1))
    keep = labels == (int(np.argmax(sizes)) + 1)
    return ndimage.binary_fill_holes(keep)


def widths(mask: np.ndarray) -> dict:
    rows = np.where(mask.any(axis=1))[0]
    if rows.size == 0:
        return {"height_px": 0, "waist_px": 0, "hip_px": 0, "waist_row": 0, "hip_row": 0}
    top, bottom = int(rows[0]), int(rows[-1])
    height = bottom - top + 1
    row_width = mask.sum(axis=1)

    def band(lo: float, hi: float) -> tuple[int, int]:
        a, b = top + int(height * lo), top + int(height * hi)
        return a, max(b, a + 1)

    wa, wb = band(0.35, 0.55)
    ha, hb = band(0.50, 0.70)
    waist_row = wa + int(np.argmin(row_width[wa:wb]))
    hip_row = ha + int(np.argmax(row_width[ha:hb]))
    return {"height_px": height, "waist_px": int(row_width[waist_row]), "hip_px": int(row_width[hip_row]),
            "waist_row": waist_row, "hip_row": hip_row}


def silhouette_delta(skin: Path, suit: Path) -> dict:
    a, b = _rgb(skin), _rgb(suit)
    wa, wb = widths(dark_subject_mask(a)), widths(dark_subject_mask(b))
    limit = SILHOUETTE_LIMIT_PX_AT_1216 * a.shape[1] / 1216.0
    out = {"waist_delta_px": abs(wa["waist_px"] - wb["waist_px"]),
           "hip_delta_px": abs(wa["hip_px"] - wb["hip_px"]),
           "height_delta_px": abs(wa["height_px"] - wb["height_px"]),
           "limit_px": limit, "skin": wa, "suit": wb}
    out["ok"] = out["waist_delta_px"] < limit and out["hip_delta_px"] < limit
    return out


def _face_crop(rgb: np.ndarray) -> tuple[np.ndarray | None, int | None]:
    global _CASCADE
    if _CASCADE is None:
        _CASCADE = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
    grey = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY)
    faces = _CASCADE.detectMultiScale(grey, scaleFactor=1.1, minNeighbors=5, minSize=(48, 48))
    if len(faces) == 0:
        return None, None
    x, y, w, h = max(faces, key=lambda f: f[2] * f[3])
    crop = cv2.resize(grey[y:y + h, x:x + w], (128, 128), interpolation=cv2.INTER_AREA)
    return crop, int(w)


def face_identity(a: Path, b: Path) -> dict:
    ca, pa = _face_crop(_rgb(a))
    cb, pb = _face_crop(_rgb(b))
    if ca is None or cb is None:
        return {"mae": None, "ncc": None, "face_px_a": pa, "face_px_b": pb}
    mae = float(np.abs(ca.astype(np.float32) - cb.astype(np.float32)).mean())
    ncc = float(cv2.matchTemplate(ca, cb, cv2.TM_CCOEFF_NORMED)[0, 0])
    return {"mae": mae, "ncc": ncc, "face_px_a": pa, "face_px_b": pb}


if __name__ == "__main__":
    skin, suit = Path(sys.argv[1]), Path(sys.argv[2])
    print(json.dumps({"silhouette": silhouette_delta(skin, suit), "identity": face_identity(skin, suit)}, indent=1))
```

```python
# scripts/dev/wrought_sheet_test.py
"""Can the native reference path turn a Lane-A skin plate into a flat-lit F/B/L/R sheet that keeps
the person? Twenty plates, measured, before any LoRA or node pack is downloaded (owner decision 6).

The sheet is a BUILD DOCUMENT: it is checked against CHARACTER_IMAGE_INPUT_SPEC (A-pose, plain
ground, flat light, >=1024 px, one figure, consistent scale) by check_reference_sheet.py, and it does
NOT carry the Wrought look -- the pipeline doc records that the look lives in the lighting law and
cannot survive the sheet. Owner decision 7: if the path cannot re-light to flat, a directional-soft
key that is flat enough for 3D is accepted; both are run and reported side by side.

Identity is measured, not eyeballed: face MAE/NCC between the skin plate and the front view, and
between front and back for scale via the checker's cross-view rule.
"""
from __future__ import annotations

import argparse
import glob
import json
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import wrought_comfy as wc  # noqa: E402
import wrought_measures as measures  # noqa: E402
from check_reference_sheet import check_set  # noqa: E402
from generate_reference_sheet import NEGATIVE as PLATE_NEGATIVE, VIEW_WIDTH, VIEWS  # noqa: E402

REPO = Path(__file__).resolve().parents[2]
H = 1728
SHEET_LIGHT = {
    "flat": "even soft frontal studio lighting, no harsh shadows, no key light",
    "soft": "soft directional light from the upper left with gentle fill, low contrast, no hard shadow",
}


def sheet_prompt(view: str, light: str) -> str:
    return ", ".join([
        "one single figure alone, the same woman as the reference, identical face, hair, skin and build",
        "wearing the same plain black sports bra and fitted shorts, barefoot",
        "neutral A-pose with the arms held away from the sides, feet shoulder width apart",
        VIEWS[view], SHEET_LIGHT[light],
        "plain seamless light grey studio backdrop, orthographic character reference sheet",
        "whole figure with generous empty margin on all sides, hands well inside the frame",
    ])


def sheet_negative(light: str) -> str:
    extra = ", dark background, dramatic shadows, key light, vignette" if light == "flat" else ""
    return PLATE_NEGATIVE + extra


def run_sheet(endpoint: wc.Endpoint, skin_plate: Path, out_dir: Path, light: str, seed: int) -> dict:
    out_dir.mkdir(parents=True, exist_ok=True)
    ref = endpoint.upload(skin_plate)
    stem = f"{skin_plate.parent.name}_{skin_plate.stem}_{light}"
    files: dict[str, Path] = {}
    t0 = time.time()
    for i, view in enumerate(("front", "back", "left", "right")):
        target = out_dir / f"{stem}_{view}.png"
        graph = wc.reference_edit_graph(sheet_prompt(view, light), sheet_negative(light), seed + i,
                                        f"wsheet_{stem}_{view}", VIEW_WIDTH[view], H, ref)
        if wc.render(endpoint, graph, target):
            files[view] = target
    report = check_set([files[v] for v in ("front", "back", "left", "right") if v in files]) if files else {}
    identity = measures.face_identity(skin_plate, files["front"]) if "front" in files else {}
    per_image = {Path(r["path"]).stem.rsplit("_", 1)[-1]: sum(f["ok"] for f in r["findings"]) / max(len(r["findings"]), 1)
                 for r in report.get("images", [])}
    result = {"plate": str(skin_plate), "light": light, "seed": seed, "seconds": round(time.time() - t0, 1),
              "files": {k: v.name for k, v in files.items()}, "per_image_pass_fraction": per_image,
              "cross_view_ok": all(f["ok"] for f in report.get("cross_view", [])) if report else False,
              "identity": identity, "report": report}
    (out_dir / f"{stem}_sheet.json").write_text(json.dumps(result, indent=1), encoding="utf-8")
    return result


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--plates", nargs="+", required=True, help="skin plates or globs")
    parser.add_argument("--n", type=int, default=20)
    parser.add_argument("--light", choices=list(SHEET_LIGHT), default="flat")
    parser.add_argument("--out", default=str(REPO / "runtime/wrought_sheet_test"))
    parser.add_argument("--api", default="http://127.0.0.1:8188")
    parser.add_argument("--seed", type=int, default=31000)
    args = parser.parse_args()
    plates = sorted({Path(p) for raw in args.plates for p in (glob.glob(raw) or [raw])})[: args.n]
    endpoint = wc.Endpoint(args.api)
    rows = []
    for i, plate in enumerate(plates):
        r = run_sheet(endpoint, plate, Path(args.out), args.light, args.seed + 10 * i)
        rows.append(r)
        ident = r["identity"]
        print(f"{plate.name:22s} views ok {sum(v >= 0.99 for v in r['per_image_pass_fraction'].values())}/4 "
              f"cross {'ok' if r['cross_view_ok'] else 'FAIL'} mae {ident.get('mae')} ncc {ident.get('ncc')} "
              f"{r['seconds']}s", flush=True)
    summary = {"light": args.light, "n": len(rows),
               "sheets_fully_passing": sum(all(v >= 0.99 for v in r["per_image_pass_fraction"].values())
                                           and r["cross_view_ok"] for r in rows),
               "median_ncc": sorted(r["identity"].get("ncc") or 0 for r in rows)[len(rows) // 2] if rows else None}
    (Path(args.out) / f"_summary_{args.light}.json").write_text(json.dumps(summary, indent=1), encoding="utf-8")
    print(json.dumps(summary, indent=1))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
